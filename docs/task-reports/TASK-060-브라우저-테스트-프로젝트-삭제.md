# TASK-060. 수동 브라우저 테스트: 프로젝트 삭제 → 소프트 삭제/휴지통 확인

## 상태
완료

## 날짜
2026-10-21

## 작업 요약
상세 페이지의 "삭제" 버튼(T059와 함께 추가)을 클릭해 소프트 삭제를 수행했다. 삭제 즉시 대시보드(`/`)로 리다이렉트되고, 대시보드 목록에는 더 이상 표시되지 않음을 확인했다 ("아직 프로젝트가 없습니다" 안내문 표시).

Trash 전용 화면(T181, Phase 10)이 아직 구현되지 않아 "휴지통 가시성"을 UI로는 확인할 수 없었으므로, 백엔드 DB를 직접 조회해 소프트 삭제 필드를 검증했다:
- `deletion_status`: `"trashed"`
- `trashed_at`: `2026-10-21 14:22:55+00:00`
- `scheduled_deletion_at`: `2026-11-20 14:22:55+00:00` (trashed_at + 정확히 30일)

ProjectService.soft_delete(T044)가 설계한 대로 동작함을 실제 브라우저 액션 → 실제 DB 상태로 end-to-end 확인했다.
